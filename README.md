## 💡 为什么做这个

每个行业都有自己的黑话：SaaS 的 ARR，智能驾驶的 BEV、L4，生物医药的 CXO……

面对一个陌生赛道，真正卡住创业者、战略分析师、投研人的从来不是「看不懂道理」，而是「**这些词是啥**」。

IndustryLens 做的事只有一件：

**给你一把透镜 —— 每个行业用 100 个关键词把它的全貌摊开。**

每个词都有两层解释：
- 🎓 **专业释义**：招股书/研报里会这么说
- 🗣️ **大白话翻译**：你妈都能听懂

## ✨ 核心功能

| 能力 | 说明 |
|------|------|
| 🔎 **智能搜索** | 输入行业名 / 公司名 / 技术词，三层 Tier 置信度匹配，99% 场景秒开 |

| 🔗 **外链直通** | 每个关键词附带 Google、Wikipedia 一键跳转，深挖有路径 |
| 🔗 **URL 可分享** | hash 路由支持刷新保留 / 链接分享 / 浏览器回退 |

## 🚀 快速启动

### 在线使用
直接访问：**https://znzjluo1008-netizen.github.io/industrylens/**

### 本地运行

```bash
# 1. 克隆
git clone https://github.com/znzjLuo1008-netizen/industrylens.git
cd industrylens

# 2. 起个静态服务（任选）
python3 -m http.server 8891
# 或 npx serve .

# 3. 浏览器打开
open http://localhost:8891
```

### 配置 AI（可选）

本地命中率 90%+，**不配 AI 也能用**。想启用 AI 兜底，两种方式：

**方式一**（推荐，开发用）：新建 `config.local.js`（已在 gitignore）

```js
window.__DS_KEY__ = 'sk-你的DeepSeek密钥';
```

**方式二**（普通用户）：打开网页右上角 ⚙️ 设置面板，把 DeepSeek API Key 粘进去（存在浏览器 localStorage，不上传）。

申请 Key 👉 [platform.deepseek.com](https://platform.deepseek.com/)

## 🏗 技术架构

**纯前端 SPA，无需构建，一个 HTML 拖出来就能跑。**

```
index.html                ← 单页入口（含 CSS/JS）
├── synonyms.js           ← 三层 Tier 置信度匹配
├── ai-service.js         ← DeepSeek 流式 + localStorage 缓存
├── companies.js          ← 行业三强数据库
├── keywords.js           ← 行业 ↔ 关键词文件映射
├── kw_<industry>.js      ← 各行业独立词库（109 个，按需懒加载）
├── VOCABULARY.md         ← 词库总览
└── bg-clay.png / img/    ← 3D 粘土背景 + 品牌素材
```

### 关键设计

| 问题 | 方案 |
|------|------|
| 词库大、首屏慢 | 按行业拆 `kw_*.js`，命中后才加载 |
| AI 贵、慢、不稳定 | 本地优先 → localStorage 30 天缓存 → 最后才调 AI |
| 匹配精度 | 三层 Tier：全词命中 → 同义词 → 拼音首字母，带加权 |
| 错误兜底 | 前端黑名单 + AI prompt 铁律，防"意大利→红酒"这类错匹 |
| 刷新/分享 | `#hash` 路由，刷新不丢状态，链接可收藏 |

## 🎨 设计语言

- **配色**：Natural Palette（青绿色系）
  `#00AAB8 · #4FC2C8 · #7FD3D6 · #B8E4E3 · #E6F4F1`
- **字体**：Space Grotesk（标题）· Inter（正文）· Noto Sans SC（中文）
- **质感**：3D 粘土背景 + 玻璃态蒙版（`backdrop-filter: blur`）
- **动效**：背景 22s 呼吸 · 卡片 9s 漂浮 · 加载透镜扫描球
- **文案铁律**：研报视角（生态位 / 护城河 / 生命周期），**拒绝投资化语言**（目标价 / PE / DCF）
