## 💡 为什么做这个

每个行业都有自己的黑话：SaaS 的 ARR，智能驾驶的 BEV、L4，生物医药的 CXO……

面对一个陌生赛道，真正卡住创业者、战略分析师、投研人的从来不是「看不懂道理」，而是「**这些词是啥**」。

IndustryLens 做的事只有一件：

**给你一把透镜 —— 每个行业用 30 个最关键的术语把它的全貌摊开。**

每个词都有四层信息：

- 📖 **专业释义**：招股书 / 研报里会这么说，含数据和趋势
- 🔍 **查资料**：一键跳转 Wikipedia / Google
- 📈 **行业数据**：参考数据、典型公司、市场份额
- 💬 **大白话**：你妈都能听懂

## ✨ 核心功能

| 能力 | 说明 |

### 配置 AI（可选）

预加载数据已覆盖 109 个行业，**不配 AI 也能用 90% 场景**。想启用 AI 实时生成新行业关键词，两种方式：

**方式一**（推荐，开发用）：新建 `config.local.js`（已 gitignore）

```js
window.__DS_KEY__ = 'sk-你的DeepSeek密钥';
```

**方式二**（普通用户）：打开网页右上角 ⚙️ 设置面板，把 DeepSeek API Key 粘进去（存在浏览器 localStorage，不上传）。

申请 Key 👉 [platform.deepseek.com](https://platform.deepseek.com/)

## 🏗 技术架构

**纯前端 SPA，零构建，单 HTML 拖出来就能跑。**

```
index.html                ← 单页入口（含 CSS/JS）
├── preloaded_data.js     ← 109 行业全量预生成（关键词 + 公司，~1.5MB）
├── ai-service.js         ← DeepSeek 流式调用 + localStorage 30 天缓存
├── companies.js          ← 行业三强数据兜底（COMPANIES_DB 占位）
├── synonyms.js           ← 三层 Tier 置信度匹配
├── keywords.js           ← 行业映射兜底
├── VOCABULARY.md         ← 词库总览
└── bg-clay.png / img/    ← 3D 粘土背景 + 品牌素材
```

### 关键设计

| 问题 | 方案 |
|------|------|
| 首屏速度 | 预加载 `preloaded_data.js` 注入 `KEYWORDS_DB / COMPANIES_DB`，命中即秒显 |
| AI 贵、慢、不稳定 | 本地优先 → localStorage 30 天缓存 → 最后才调 AI |
| 匹配精度 | 三层 Tier：全词命中 → 同义词 → 拼音首字母，带加权 |
| 数据可信度 | AI prompt 铁律：研报视角，禁编造；进度条单项 100% 显示"未公开"兜底 |
| 刷新 / 分享 | `#hash` 路由，刷新不丢状态，链接可收藏 |
| 大文件推送 | GitHub Contents API + base64 + Python 写临时 JSON 绕开 shell 截断 |

## 🎨 设计语言

- **配色**：浅色极简 · 主色 #166534（深绿）+ #0F6E56（青）+ #185FA5（链接蓝）
- **字体**：Space Grotesk（标题）· Inter（正文）· Noto Sans SC（中文）
- **卡片风格**：白底 + 0.5px 细分隔线 + 圆角 16px，仅"大白话"区块带淡绿底（情感锚点）
- **数字高亮**：百分比 / L 等级自动加超链接样式（蓝底 + 下划线）
- **动效**：背景 14s 呼吸 · 卡片 IntersectionObserver 滚动渐入
- **文案铁律**：研报视角（生态位 / 护城河 / 生命周期），**拒绝投资化语言**（目标价 / PE / DCF）

## 📌 数据来源说明

- **词库**：基于各行业招股书 / 研报 TF-IDF 提取 + 人工筛选 + LLM 补全（DeepSeek 批量生成 v3）
- **行业三强**：公开财报、招股书、年报的可查数据，**禁编造**
- **同义词 / 拼音**：人工维护 + 自动生成混合
